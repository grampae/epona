## Summary

Print the current working directory.
- Needs Admin: False
- Supported OS: Linux, macOS, Windows
- Version: 1
- Author: @grampae

## Usage

```
pwd
```

## MITRE ATT&CK Mapping

None

## Detailed Summary

Returns the absolute path of the agent's current working directory. The working directory can be changed with `cd`.
